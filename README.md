# 十一罗汉房贷计算器 · ShiLuohan Mortgage Calculator

> 支持商业贷款、公积金贷款、组合贷款；等额本息 / 等额本金；贷款期限最长 **480 期（40 年）**；利率手动输入，无下拉选项。

纯前端单文件实现，零依赖构建、零后端。打开 `index.html` 即可使用。

## 首套房公积金基础贷款额度测算

主页面顶部的「首套房公积金额度测算」入口可进入独立测算页，测算页与结果页均提供返回按钮，随时可切回主页面。计算边界为**只做首套、只做基础额度**：房屋总价 / 首付 / 成数不输入，多孩 ×1.2、绿色建筑 ×1.15 等上浮由人工另乘。

### 额度构成：两段分别封顶再相加

```
基本段可贷 = MIN(总基本余额 × 基本倍数, 基本段上限)
补充段可贷 = MIN(总补充余额 × 补充倍数, 补充段上限)
余额路合计 = 基本段可贷 + 补充段可贷
还款能力限额 = 总月收入 × 还款能力系数 × 12 × 最终可贷年限
基础可贷额度 = 向下取整( MIN(余额路合计, 还款能力限额), 取整粒度 )
```

必须分段而不能整体封顶：基本段是 30 倍 / 100 万，补充段是 10 倍 / 20 万，顶格门槛差一个量级。「基本余额 1 万 + 补充余额 10 万」分段得 50 万，整体封顶会错算成 120 万。

### 年限：双路到期日取短 → 整年差

```
硬顶到期日 = 出生日期 + (男 ? 68 : 63) 年
退休路到期日 = 出生日期 + (退休月数 + 退休后延年数×12) 个月   # 双路取短仅在过渡期启用
取短后到期日 = MIN(退休路到期日, 硬顶到期日)
年龄可贷年限 = FLOOR_FULL_YEARS(受理日, 取短后到期日)
最终可贷年限 = MAX(1, MIN(年龄可贷年限, 房龄可贷年限))
```

退休月数用公式实现，不硬编码大表：

```
男：      60×12 + MIN(MAX(FLOOR((ym − (1965×12+1)) / 4) + 1, 0), 36)
女管理岗：55×12 + MIN(MAX(FLOOR((ym − (1970×12+1)) / 4) + 1, 0), 36)
女工人岗：50×12 + MIN(MAX(FLOOR((ym − (1975×12+1)) / 2) + 1, 0), 60)
```

两个到期日必须分别算出再取短，不能先把两条路各自化成「年限」再比较——跨月场景会差一年。

### 资格闸门：已到/已过法定退休日 → 额度 0

受理日 ≥ 出生日期 + 退休月数（即已到法定退休年龄）时，直接返回额度 0 并在结果页标红说明，不再进入年限与额度计算。退休月数公式对区间外的出生日期同样收敛，所以非过渡期人群也能判定；该闸门与「年限口径」三档开关无关——它是资格问题，不是年限算法问题。

### 结果页展示

- **两路取低**：余额路与还款能力路按同一比例画条，标注哪一路更低
- **年限从哪来**：三级推导链，逐级给出退休路 / 硬顶 / 取短 / 房龄，回答「为什么是 11 年而不是 13 年」
- **额度明细**：基本段、补充段分别标注「已顶上限 / 倍数未满」，两者结论相反，不能只给一个「余额卡住」
- **口径提示**：含补充总额度上限（个人 120 万 / 家庭 240 万），作为人工上浮的基数

### 可配参数

贷款受理日、男/女年龄上限、退休后延年数、最长贷款年限、基本/补充倍数、基本/补充段上限（单人 / 夫妻）、还款能力系数、房龄年限基准、取整粒度，以及用于与系统对拍的**年限口径开关**（双路取短 / 仅硬顶 / 仅退休表）。页面底部「测算参数」折叠面板可改，结果页记录本次计算使用的参数快照。

## 计算算法

### 等额本息（每月还款额固定）

```
月利率 r = 年利率 / 12
月供 M = P × r × (1 + r)^n / [(1 + r)^n − 1]

P = 贷款本金
n = 还款期数（月）
```

其中每月利息 = 剩余本金 × r，每月本金 = M − 每月利息。

### 等额本金（每月本金固定，月供递减）

```
每月本金 = P / n
第 k 期利息 = 剩余本金(k) × r
第 k 期还款 = 每月本金 + 第 k 期利息
```

### 组合贷款

商业贷款与公积金贷款分别按各自金额、利率、期限计算完整还款计划，再按期次逐月相加，得到合并后的每期还款、利息与剩余本金。

### 收入证明参考

行业惯例按「月供不超过月收入 50%」核定，因此页面展示 月供 × 2 作为最低月收入证明金额。

> ⚠️ 计算结果仅供参考，实际额度、利率与还款以贷款银行审批为准。本工具不构成任何金融建议。

## 本地使用

直接双击 `index.html` 用浏览器打开即可，无需安装任何依赖、无需启动服务器。

如需本地起服务（可选）：

```bash

python3 -m http.server 8080

# 或 Node.js
npx serve .
```

## 技术说明

- 单文件 HTML，样式与脚本内联，无构建步骤
- 图表使用 [Chart.js 4.4.1](https://www.chartjs.org/)（CDN 引入）；若 CDN 不可用，数值计算与明细表仍可正常工作，仅图表不渲染
- 响应式布局，最大内容宽度 480px，适配手机与桌面
- 支持系统级深色模式（`prefers-color-scheme`）
- 所有计算在浏览器本地完成，不上传任何数据，不写入 localStorage / Cookie
