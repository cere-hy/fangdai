# 十一罗汉房贷计算器 · ShiLuohan Mortgage Calculator

> 支持商业贷款、公积金贷款、组合贷款；等额本息 / 等额本金；贷款期限最长 **480 期（40 年）**；利率手动输入，无下拉选项。

纯前端单文件实现，零依赖构建、零后端。打开 `index.html` 即可使用。

## 功能

| 模块 | 说明 |
| --- | --- |
| 还款方式 | 等额本息 / 等额本金，结果页可随时切换对比 |
| 贷款方式 | 商业贷款 / 公积金贷款 / 组合贷款（组合贷款按笔分别计算后合并） |
| 贷款期限 | 支持「按揭年数」与「按揭(月)期数」两种录入方式，上限 480 期 = 40 年，超出自动收敛到 480 |
| 利率 | 纯手工输入年利率（%），保留两位小数，支持任意值（如 LPR + 基点后的实际利率）。初始默认值：商业贷款 **3.05%**、公积金贷款 **2.6%** |
| 结果页 | 每月还款、收入证明参考（月供 × 2）、利息总额、累计还贷总额、贷款总额、还款期数 |
| 图表 | 本金 / 利息构成环形图；每期本金与利息走势曲线 |
| 对比 | 等额本息 vs 等额本金的月供、总利息、总还款条形对比 |
| 月供明细 | 按自然年折叠，点击年份展开逐月明细，含每期还款与剩余本金 |
| 分项卡片 | 组合贷款时分别展示商业贷款、公积金贷款的月供与利息 |

## 计算算法

### 等额本息（每月还款额固定）

```
月利率 r = 年利率 / 12
月供 M = P × r × (1 + r)^n / [(1 + r)^n − 1]

P = 贷款本金
n = 还款期数（月）
```

其中每月利息 = 剩余本金 × r，每月本金 = M − 每月利息。

### 等额本金（每月本金固定，月供递减）

```
每月本金 = P / n
第 k 期利息 = 剩余本金(k) × r
第 k 期还款 = 每月本金 + 第 k 期利息
```

### 组合贷款

商业贷款与公积金贷款分别按各自金额、利率、期限计算完整还款计划，再按期次逐月相加，得到合并后的每期还款、利息与剩余本金。

### 收入证明参考

行业惯例按「月供不超过月收入 50%」核定，因此页面展示 月供 × 2 作为最低月收入证明金额。

> ⚠️ 计算结果仅供参考，实际额度、利率与还款以贷款银行审批为准。本工具不构成任何金融建议。

## 本地使用

直接双击 `index.html` 用浏览器打开即可，无需安装任何依赖、无需启动服务器。

如需本地起服务（可选）：

```bash
# Python 3
python3 -m http.server 8080

# 或 Node.js
npx serve .
```

然后访问 http://localhost:8080

## 技术说明

- 单文件 HTML，样式与脚本内联，无构建步骤
- 图表使用 [Chart.js 4.4.1](https://www.chartjs.org/)（CDN 引入）；若 CDN 不可用，数值计算与明细表仍可正常工作，仅图表不渲染
- 响应式布局，最大内容宽度 480px，适配手机与桌面
- 支持系统级深色模式（`prefers-color-scheme`）
- 所有计算在浏览器本地完成，不上传任何数据，不写入 localStorage / Cookie
